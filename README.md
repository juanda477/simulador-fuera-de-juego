# Simulador de fuera de juego / Offside simulator

PWA bilingüe (es/en). Publicación en GitHub Pages desde la raíz de la rama configurada. El simulador funciona sin servicios de IA.

Para agregar un idioma, crea `locales/xx.json` con las mismas claves y añade una opción al selector `#lang-picker` en `index.html`. Para futuras versiones, cambia el nombre `CACHE` en `service-worker.js` (por ejemplo, de `v4` a `v5`).
